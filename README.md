# Community Issue Reporter

A React Native mobile application for reporting community issues such as potholes, damaged signs, trash, streetlight problems, and drainage issues.

Users can enter issue information, select a location on Google Maps, save reports to Firebase, and receive a local notification after submission.

## Features
- Four application screens
- Submit community issue reports
- Google Maps integration
- Select report locations with map markers
- Firebase Realtime Database storage
- View previously submitted reports
- View submitted reports on a map
- Local notifications after submission
- Dark themed interface

## Built With
- React Native
- Expo
- TypeScript
- Firebase Realtime Database
- Google Maps
- React Navigation
- Expo Notifications

## Running the Application
- Install dependencies: `npm install`
- Start development server: `npx expo start --dev-client`
- Run Android development build: `npx expo run:android`

## Project Purpose
- Final project for ACS-5413
- Demonstrates mobile navigation and user input
- Uses Google Maps for location selection
- Stores report data in Firebase
- Uses local notifications for submission confirmation
- Combines application functionality with a styled mobile interface
